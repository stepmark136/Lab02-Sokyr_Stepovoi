# ПР2. Ответы на контрольные вопросы

### 1. Почему для хранения денег используют decimal, а не double?

Как я понял, `double` может давать небольшую погрешность при вычислениях с десятичными числами. Для денег это может быть проблемой, поэтому используют `decimal`, который точнее работает с такими значениями.

### 2. Что будет при переполнении byte?

Я понял это так: если значение выходит за границы `byte` (0–255), происходит переполнение. Например, 255 + 1 может превратиться в 0.

### 3. Чем var отличается от динамической типизации?

`var` сам определяет тип переменной при компиляции, но потом тип изменить нельзя. В Python тип переменной может меняться во время работы программы.

### 4. Что возвращает Console.ReadLine()?

`Console.ReadLine()` всегда возвращает `string`, то есть строку. Даже если я ввёл число, сначала оно будет текстом.

### 5. Чем Parse отличается от TryParse?

Как я понял, `Parse` при неправильном вводе выдаёт ошибку. `TryParse` просто возвращает `false`, поэтому программа не падает из-за неправильного ввода.

### 6. Что означает false в TryParse?

`false` означает, что преобразовать значение в число не получилось. В переменную `out` при этом попадёт стандартное значение для `int` — `0`.

### 7. Когда использовать TryParse?

Я бы использовал `TryParse`, когда данные вводит пользователь. Ведь пользователь может ввести что-то неправильно, и лучше показать ошибку, чем завершить программу.
